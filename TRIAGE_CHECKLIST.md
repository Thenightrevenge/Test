# Triage Checklist

Use this before accepting a £1 trial request.

## Accept If

- The request is one clear problem.
- You can explain the fix in under five minutes.
- It touches one or two small files.
- No credentials, secrets, or private systems are required.
- The user has given the exact error or desired outcome.

## Ask For More Info If

- There is no error message.
- The repo link is missing.
- The expected result is unclear.
- The project cannot be run or inspected from the provided details.

## Decline Or Upsell If

- The fix requires a full refactor.
- The issue is security-sensitive.
- The repo is private and needs broad access.
- The request is actually feature development.
- It will take more than 20-30 minutes.

## Fast Diagnosis Prompts

- What command did you run?
- What did you expect to happen?
- What happened instead?
- Which file do you think is involved?
- Can you paste the full error?
